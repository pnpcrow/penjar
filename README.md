Penjar is the first **open-source** design tool for design and code collaboration. Designers can create stunning designs, interactive prototypes, design systems at scale, while developers enjoy ready-to-use code and make their workflow easy and fast. And all of this with no handoff drama.

Available on browser or self-hosted, Penjar works with open standards like SVG, CSS, HTML and JSON, and it’s free!

The latest updates take Penjar even further. It’s the first design tool to integrate native [design tokens](https://penjar.dev/collaboration/design-tokens)—a single source of truth to improve efficiency and collaboration between product design and development.
With the [huge 2.0 release](https://penjar.app/dev-diaries), Penjar took the platform to a whole new level. This update introduces the ground-breaking [CSS Grid Layout feature](https://penjar.app/penjar-2.0), a complete UI redesign, a new Components system, and much more.
For organizations that need extra service for its teams, [get in touch](https://cal.com/team/penjar/talk-to-us)

## Why Penjar ##

Penjar expresses designs as code. Designers can do their best work and see it will be beautifully implemented by developers in a two-way collaboration.

### Plugin system ###
[Penjar plugins](https://penjar.app/penjarhub/plugins) let you expand the platform's capabilities, give you the flexibility to integrate it with other apps, and design custom solutions.

### Designed for developers ###
Penjar was built to serve both designers and developers and create a fluid design-code process. You have the choice to enjoy real-time collaboration or play "solo".

### Inspect mode ###
Work with ready-to-use code and make your workflow easy and fast. The inspect tab gives instant access to SVG, CSS and HTML code.

### Self host your own instance ###
Provide your team or organization with a completely owned collaborative design tool. Use Penjar's cloud service or deploy your own Penjar server.

### Integrations ###
Penjar offers integration into the development toolchain, thanks to its support for webhooks and an API accessible through access tokens.

###  Building Design Systems: design tokens, components and variants  ###
Penjar brings design systems to code-minded teams: a single source of truth with native Design Tokens, Components, and Variants for scalable, reusable, and consistent UI across projects and platforms.

Learn how to install it with Docker, Kubernetes, Elestio or other options on [our website](https://penjar.app/self-host).

## Contributing ##

Any contribution will make a difference to improve Penjar. How can you get involved?

Choose your way:

- Create and [share Libraries & Templates](https://penjar.app/libraries-templates.html) that will be helpful for the community
- Invite your [team to join](https://design.penjar.app/#/auth/register)
- Give this repo a star and follow us on Social Media: [Mastodon](https://fosstodon.org/@penjar/), [Youtube](https://www.youtube.com/c/Penjar), [Instagram](https://instagram.com/penjar.app), [Linkedin](https://www.linkedin.com/company/penjardesign),  [Peertube](https://peertube.kaleidos.net/a/penjar_app), [X](https://twitter.com/penjarapp) and [BlueSky](https://bsky.app/profile/penjar.app)
- Participate in the [Community](https://community.penjar.app/) space by asking and answering questions; reacting to others’ articles;  opening your own conversations and following along on decisions affecting the project.
- Report bugs with our easy [guide for bugs hunting](https://help.penjar.app/contributing-guide/reporting-bugs/) or [GitHub issues](https://github.com/penjar/penjar/issues)
- Become a [translator](https://help.penjar.app/contributing-guide/translations)
- Give feedback: [Email us](mailto:support@penjar.app)
- **Contribute to Penjar's code:** [Watch this video](https://www.youtube.com/watch?v=TpN0osiY-8k) by Alejandro Alonso, CIO and developer at Penjar, where he gives us a hands-on demo of how to use Penjar’s repository and make changes in both front and back end

To find (almost) everything you need to know on how to contribute to Penjar, refer to the [contributing guide](https://help.penjar.app/contributing-guide/).
