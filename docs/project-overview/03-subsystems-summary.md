# 03. 주요 서브시스템별 역할

## backend

- 인증, 권한, 파일/오브젝트 관리, 태스크 처리, 마이그레이션 등 서버 핵심 기능 담당
- `src/app/migrations`에 SQL/클로저 마이그레이션이 공존

## frontend

- 에디터 UI, 워커, 테스트, 스토리북, 스타일/리소스 파이프라인을 포함
- 도메인 로직 일부가 ClojureScript 레이어에 녹아 있어 컴파일 파이프라인 이해가 중요

## common

- 백/프론트 공유 유틸 및 계약(데이터 구조, 공통 헬퍼 등)을 담당
- 변경 시 양쪽 영향도가 커서 우선적으로 회귀 확인 필요

## render-wasm

- 캔버스 렌더링 성능을 위해 Rust 기반 WASM 엔진 제공
- 빌드 결과물이 프론트엔드 런타임에 연결됨

## plugins

- 플러그인 런타임, 샘플 플러그인, e2e 테스트를 제공
- 외부 확장성(생태계) 관점에서 중요한 영역

## mcp

- LLM과 Penpot를 연결하는 MCP 서버/플러그인
- 디자인 데이터 조회/수정/생성 자동화 시나리오를 담당

## library

- 외부 코드에서 Penpot 파일(.penpot) 생성/내보내기를 지원하는 npm 패키지
- 디자인 파일 자동 생성 파이프라인 구축에 활용 가능
