# Penjar plugin-styles

This plugin contains a CSS file to help build the UI for Penjar plugins.

### Getting started

Install the package:

```bash
npm install @penjar/plugin-styles
```

Import the CSS file into your project:

```css
@import '@penjar/plugin-styles/styles.css';
```

### Usage

For detailed examples and to see how to use the styles and components, visit the documentation at:

[Penjar Plugin Styles Documentation](https://styles-doc.plugins.penjar.app)

#### Icons

We recommend using Feather icons for Penjar plugins to ensure consistency with Penjar's design.

You can find Feather icons at: [Feather Icons](https://feathericons.com/)
